# 그림책 콘텐츠 QA — 2026-09-14

## 검토 범위와 판단

운영에서 생성한 가상 인물의 책 「별이의 따뜻한 밤」 8쪽과 실제 삽화 8장을 읽었다. 이어서 3세·6세·10세의 서로 다른 입력과 A/B/C 선택으로 실제 텍스트 생성 파이프라인을 비교했다. 1차 검수 당시에는 기존 저장된 원고를 수정하지 않았다. 이후 사용자가 수정을 요청해 752번 책의 원본을 백업하고 본문과 선택지를 교정했다. 후속 검증 결과는 이 문서 끝에 기록한다.

`~했다/~었다`는 동화에 사용할 수 있는 서술체다. 해요체만 정답이라는 판단은 하지 않는다. 호담은 부모가 잠자리에서 읽어주는 제품이므로 **새 책에는 따뜻한 해요체를 기본값으로 선택**했다. 이미 읽기 시작한 책을 이어 쓸 때는 앞 4쪽의 문체를 유지한다. 이 기준은 호담의 편집 방향이며, 연령별 문학성에 대한 객관적인 판정 기준은 아니다.

독립 편집 검토에서도 감정 해설, 추상적인 온기의 반복, 재시도 과정 생략, 모호한 선택지, 약한 결말 연결을 주요 문제로 지적했다.

## 생성 로직에서 확인한 원인

1. 본문 문체는 명시하지 않고 선택지에만 `~요`를 요구했다. 선택지 예시는 “손 내밀기, 작게 말하기” 같은 명사형이었다. 모델이 그 예시에 `요`를 붙이면 기존 길이·종결 검사에 통과했다.
2. 연령 입력은 전달했지만 문장 호흡·어휘·비유에 대한 연령별 지침이 없었다. 결말 재작성 요청에는 독자 연령과 부모 입력 맥락도 빠져 있었다.
3. 품질 재작성은 별도의 품질 점수를 매기는 과정이 아니다. 같은 모델에 원고를 다시 쓰게 하고 응답 형식을 검사했다. 구조가 맞는다는 사실만으로 문학성이 좋아졌다고 볼 수 없다.
4. 실제 비교 생성에서 결말 재작성은 정상 응답했지만 `qualityNotes`와 `revisionNotes`를 문자열로 반환했다. 배열만 허용하는 파서가 이를 거절해 수정 원고 대신 유효한 초안을 보존했다. 시간 초과와 구분되는 응답 형식 문제였다.
5. 각 쪽 이미지는 독립 요청인데 인물·의상 외형이 각 `imagePrompt`에 충분히 반복되지 않았다.

## 1차 수정 내용

- 새 원고의 서술은 해요체, 기존 책을 이어 쓸 때는 기존 문체로 작성하도록 분리했다. 인물의 대사는 자연스러운 말투를 허용한다.
- 3–4세·5–7세·8세 이상에 대해 문장 호흡, 생활 어휘, 비유의 밀도를 다르게 안내한다. 글자 수만으로 좋은 문장을 판정하지 않는다.
- 명사형+요, 요요 중복, 동일 선택지 반복을 검증한다. 문장형이 잘못된 초안은 기존 1회 재작성 안에서 교정할 수 있다. 교정 실패 시 유효한 초안만 보존하고, 둘 다 부적합하면 저장·곶감 차감 전에 실패한다.
- 결말 재작성에도 부모의 상황·전하고 싶은 마음·톤·관심사를 전달하고 반환 JSON 및 메모 배열 형식을 명시한다.
- 갈등의 핵심 물건, 망설임의 계기, 작은 재시도, 마지막 잠자리 장면을 연결하도록 지침을 보완한다.
- 이미지 프롬프트는 각각 독립적으로 인물·의상·소품을 설명하도록 요구한다. 이번 텍스트 평가에서는 새 삽화를 생성하지 않았다.

```sh
# 기본 실행은 도움말만 표시하며 API를 호출하지 않는다.
node scripts/qa-picturebook.mjs

# 가상 사례 3개를 실제 OpenAI 모델로 작성한다. API 크레딧을 사용한다.
# 인증만 테스트용 대역으로 바꾸며 DB 쓰기·이미지 생성·곶감 차감은 하지 않는다.
node scripts/qa-picturebook.mjs --run-live --label revised

# 특정 사례 또는 기존 생성기 파일과 비교
node scripts/qa-picturebook.mjs --run-live --label night-only --case night
node scripts/qa-picturebook.mjs --run-live --label baseline --source-ref 4960b7d2b9d3c72830de54d1f0b3dfa1ce0e73b9
```

`--source-ref`는 해당 커밋의 생성기 파일을 현재 유틸리티와 함께 실행한다. 결과 원고·호출별 응답·토큰 사용량은 Git에서 제외된 `reports/local/picturebook-evals/<label>/`에 저장된다. 자동 CI에는 유료 평가를 추가하지 않는다. 실제 사용자 정보를 평가 입력에 넣지 않는다.

표본 생성은 오류 재현과 편집 비교를 위한 것이다. 모든 연령·소재에 대한 품질 보장이나 아이와 부모의 실제 사용 평가를 대신하지 않는다.

## 1차 편집 판정: 서사 품질 추가 개선 필요

확실한 형식 오류는 수정했으나 콘텐츠 전체가 QA를 통과했다고 판단하지 않는다. 독립 편집 검토와 실제 원고에서 다음 문제가 남았다.

1. **인물·사물 구분과 문장 의미.** 최종 4o-mini 밤 이야기에서 아이 이름 ‘별이’와 사물 ‘작은 별’을 모두 ‘별이’로 부른다. “방 안의 조용한 소리와 별이의 작은 심장이 쿵쿵 뛰었어요”는 주어와 서술어가 어울리지 않는다.
2. **입력한 갈등 유지.** 4.1-mini의 3세 책에서는 친구가 삽을 쓰고 싶어 한 상황이 본문에서 사라지고 혼자 오리 발자국을 찍는 이야기가 됐다. 4o-mini는 친구와 놀이를 이어가지만 실제 삽을 나누는 장면은 빠졌다.
3. **선택의 약속 이행.** 4.1-mini의 10세 책에서 “연필로 별을 그리며 말해봐요”를 선택했지만 결말에 말을 하는 장면이 없었다. 두 모델 모두 이미 한 행동을 선택지에서 다시 요구하는 경우도 남았다.
4. **결말 연결.** 놀이터·학교 장면에서 이불로 이동하는 연결이 급하다. 전편이 긴장 → 상상 조력자 → 작은 행동 → 망설임 → 잠자리라는 같은 구조에 갇히는 경향도 있다.

4.1-mini는 일부 문장이 더 구체적이지만 중요한 상황과 선택을 빠뜨렸다. 이번 비교에서는 비용을 더 지불하고 운영 모델을 바꿀 만큼 명확한 우위를 확인하지 못했다. **운영 모델은 변경하지 않았다.**

다음 작업의 검증 조건은 ‘갈등·상대 인물 유지’, ‘선택한 동작 실제 수행’, ‘앞의 소재를 되받는 마지막 장면’, ‘인물 이름과 문장 의미의 명확성’이다. 무조건적인 전체 재작성 대신 이 조건에 맞는 편집 진단과 해당 쪽 교정을 평가해야 한다. 실제 그림의 인물·의상 일관성은 이미지 생성으로 별도 검증할 과제다.

## 기존 삽화에 맞춘 편집 예시

아래는 직접 다듬은 편집본이다. 후속 수정에서 운영 책 752번에 적용했다. 자동 생성 결과로 표시하지 않는다. 원본은 Git에서 제외된 `reports/local/picturebook-edits/752-before.json`에 보관하고, 기존 raw_text가 그대로일 때만 수정하는 비교 후 저장으로 반영했다. 그림·선택 A·기존 책 정보는 보존했다. 실제 적용본의 세 번째 선택은 “토끼에게 별빛을 보여줘요.”이다.

**1쪽** 불이 꺼지자 별이는 토끼 인형을 꼭 안았어요. “토끼야, 오늘도 같이 자자.” 창밖에서는 작은 별들이 반짝이고 있었어요.

**2쪽** 별이의 가슴이 콩닥콩닥 뛰었어요. “조금 무서워.” 토끼에게 속삭이자 부드러운 털이 뺨에 닿았어요.

**3쪽** 별이는 눈을 감고 작은 별들이 방에 놀러 오는 상상을 했어요. 어느새 별빛 친구들이 곁에서 반짝이는 것 같았어요.

**4쪽** 별이는 눈앞의 작은 별 하나를 바라보았어요. 이불 밖으로 나온 손끝이 꼼지락했어요.

선택 질문: “별빛 친구에게 어떻게 인사해볼까요?”

- 별빛을 향해 손을 내밀어요.
- 별에게 작은 목소리로 말해요.
- 토끼를 안고 별빛을 바라봐요.

**5쪽 — 첫 번째 선택 이후** 별이는 별빛을 향해 손을 내밀었어요. “안녕, 작은 별.” 손끝 앞에서 빛이 반짝이는 것 같았어요.

**6쪽** 어두운 방구석으로 눈길이 가자 별이는 손을 멈췄어요. 토끼를 품에 꼭 안고 속삭였어요. “조금만 기다려 줘.”

**7쪽** 토끼의 부드러운 털을 느끼며 별이는 아주 천천히 손을 내밀었어요. “안녕, 작은 별.” 이번에는 입가에 작은 웃음이 번졌어요.

**8쪽** 별이는 이불 속에서 토끼를 꼭 안았어요. “잘 자, 토끼야. 잘 자, 작은 별.” 인사를 마친 별이의 눈이 스르르 감겼어요.

## 후속 수정: 생성 시 품질 검수와 교정

사용자의 후속 수정 요청에 따라 실제 원고와 생성 파이프라인을 함께 수정했다. 위 1차 구현의 '재작성 실패 시 초안 보존' 경로는 제거했다. 현재 동작과 운영 절차는 [그림책 품질 운영 가이드](picturebook-quality.md)를 따른다.

- **기존 책:** 운영 752번의 8쪽과 선택 문장을 교정했고 브라우저에서 1–8쪽 반영을 확인했다. 기존 삽화와 선택 A는 유지했다. 원본과 수정본은 Git에서 제외된 로컬 백업에 보관했다.
- **구조:** JSON mode에서도 pages/choice가 storyGuide 안으로 잘못 들어가는 실제 응답이 나왔다. 초안에는 strict JSON Schema를 적용해 최상위 위치, 필수 필드, 페이지·선택지 수와 길이를 고정하고 서버에서도 다시 검증한다.
- **검수:** 실제 입력 충실도, 선택 행동, 연결, 언어, 낭독, 그림 설명, 정서 안전성의 7개 기준을 별도 요청으로 검수한다. 작가의 계획·해결 힌트·자기 평가를 검수 자료에서 제거했다. 결말에는 선택한 행동 하나만 전달한다. 통과 근거가 실제 원문 인용인지 서버에서 검사한다.
- **교정:** 문제가 있는 쪽만 한 번 고친 뒤 7개 기준 전체를 다시 확인한다. 결말은 앞 4쪽·선택·기존 가이드를 변경할 수 없다. 검수 불능이나 교정 후 미달이면 반환하지 않으므로 시작은 저장·곶감 차감 전에 실패하고, 결말은 기존 앞 4쪽을 보존한다.
- **맥락:** '이불을 더 꽉 안아요'를 금지 단어로 차단하던 검사를 제거했다. 안전한 행동과 빼앗는 행동은 실제 맥락으로 구분한다. 준비 몸짓과 선택 결과를 미리 실행하는 일도 구분한다. 입력에 없는 보호자·관심사 전부를 필수 등장 조건으로 만들지 않는다.
- **서사·외형:** 3–4세의 짧은 문장 기준을 우선하고, 매번 새 위기를 만들어 재시도시키는 구조를 없앴다. 새 가이드는 인물별 머리·옷 색·소품 색을 고정하고 서버가 모든 이미지 요청에 공통으로 넣는다.

기본 초안 모델과 편집 모델은 모두 `gpt-5.4-2026-03-05`, reasoning은 low로 고정했다. 서로 별도 요청으로 실행하며 `OPENAI_STORY_MODEL`은 초안, `OPENAI_STORY_REVIEW_MODEL`은 검수·교정·재검수에 적용한다. 시작·결말은 각각 50초·4회 상한을 공유하고 개별 상한은 초안 18초, 검수 20초, 교정 18초다. 무제한 재시도는 없다.

## 후속 실제 평가와 검증 결과

중간 실패도 모두 `reports/local/picturebook-evals/`에 남겼다. 예를 들어 초기 4.1-mini 검수는 알려진 오류 3개를 모두 놓쳤고, 4.1·5.4-mini 검수도 일부 의미 오류를 놓쳤다. 5.4 검수의 첫 8초 제한은 5개 전부 시간 초과였으며, 15초에서도 일부 시간 초과와 오탐이 있었다. 응답 분량과 판정 범위를 조정하고 20초 상한을 사용했다. 값싼 초안·교정 모델 조합에서도 교정 후 새 오류가 남는 원고가 있어 모델을 상향했다. 모델·프롬프트·제한 시간이 함께 바뀐 개발 실험이므로 일반적인 모델 순위나 성공률로 해석하지 않는다.

최종 설정은 알려진 오류 3개를 모두 거절하고 정상 원고 2개를 모두 통과시켜 **5/5 기대 판정과 일치**했다. 결과는 `release-structured-fixtures`에 기록했다. 새 책 생성은 `release-structured`에서 실행했다.

후속 전체 자동 검증은 **184개 파일·1,180개 테스트**, ESLint, TypeScript 및 프로덕션 빌드를 통과했다. 인용 위조, 보호 필드 변경, 잘못 중첩된 JSON, 검수·교정 실패, 모델 분리, 50초 예산, 기존 책 호환 및 곶감 보존을 포함한다.

최종 3편의 응답 사용량으로 계산한 텍스트 비용 합은 약 **$0.2884**, 평균 약 **$0.0961/권**이다. 이전 모델보다 비용이 늘었다. 입력 $2.50/백만 토큰, 캐시 입력 $0.25, 출력 $15로 계산했다. [GPT-5.4 공식 단가](https://developers.openai.com/api/docs/models/gpt-5.4). 이미지·세금은 제외하며 청구액 조회 결과가 아니다. 중간 실험 및 사용량이 반환되지 않은 시간 초과 호출 비용은 이 최종 3편 수치에 포함되지 않는다.

공통 외형의 전달과 본문·이미지 설명의 정합성은 검증했지만, 이번 텍스트 평가에서 새 이미지 픽셀은 생성하지 않았다. 독립 검수도 확률적인 모델 판단이므로 모든 소재의 문학성과 그림 일관성을 보장하지 않는다. 새로 발견한 실패 원고를 회귀 사례에 추가하는 방식으로 유지한다.

### 운영 삽화 확인 후 장면 상태 보완

운영에서 합성 입력으로 새 책 753번을 만들어 시작·선택·결말·책장 재열기를 확인했다. 8쪽 본문과 8장 삽화가 저장됐고, 곶감은 시작할 때 1개만 차감됐다. 본문과 인물 외형은 이어졌으나 3·6·7쪽 일부 스탠드가 소등 이후 다시 켜진 것을 실제 화면에서 발견했다.

원인은 개별 그림 요청이 앞 쪽의 본문·그림을 받지 않는다는 점이다. `night bedroom`만 적힌 장면은 소등 상태를 전달하지 못했고, 공통 `cozy light` 문구도 불필요한 조명을 유도할 수 있었다. 작가에게 사건에 중요한 상태를 각 장면에 이어 쓰도록 하고, 편집자는 해당 쪽 본문·imagePrompt·공통 가이드만으로 그 상태를 알 수 있는지 확인하도록 보완했다. 공통 화풍의 조명 강제도 제거했다.

변경 후 추가 생성한 8쪽 밤 이야기의 모든 장면 프롬프트에 소등 상태가 유지됐다. 실제 이미지 API로 3·6쪽 그림을 따로 생성해, 두 장 모두 켜진 스탠드 없이 밤 장면으로 그려진 것을 확인했다. 이는 표본 검증이며 앞으로의 모든 삽화가 픽셀 단위로 일치한다는 보장은 아니다. 기존 저장 삽화를 일괄 교체하지는 않았다.

재현 기록: `reports/local/picturebook-evals/scene-state-night/`. 검수 표본에는 소등 상태가 다음 요청에서 빠진 경우와 켜진 스탠드가 명시된 경우를 추가했다. 정상 결말을 기존 선택지 표기만으로 거절하는 오탐도 발견해, 결말의 언어·낭독 검수 범위를 새로 쓴 5–8쪽으로 명확히 했다.
