# 그림책을 읽은 뒤 반응 수집

완성한 개인 그림책의 마지막 화면에서 `또 읽고 싶어요` 또는 `조금 아쉬워요`를 고르고, 선택 사항으로 이유 한 가지를 남긴다. 기존 반응을 다시 불러오며 언제든 바꿀 수 있다. 저장에 실패하면 성공 메시지를 표시하지 않고 선택을 유지해 다시 시도하게 한다. 공개 샘플에서는 로그인·책 소유권이 없으므로 이 개인 책 반응 수집을 표시하지 않는다.

## 배포 순서

1. `supabase/migrations/20261008010000_reading_feedback.sql`을 적용한다. 기존 그림책을 수정하지 않는 추가 마이그레이션이다.
2. API와 화면을 배포한다. 마이그레이션 없이 실행하면 API는 503을 반환하고 화면에서 다시 확인/저장을 안내한다.
3. 완성한 내 책에서 저장 → 새로고침 → 반응 바꾸기를 확인한다. 다른 계정과 로그아웃 상태에서는 접근할 수 없어야 한다.

## 저장 및 보안

- 저장소: `public.reading_feedback`. `(user_id, thread_id)` 복합 기본 키로 책마다 최신 반응 한 개만 유지한다.
- 저장 값: `rating`, 선택적 `reason`, 서버 생성 시각. 아이 이름·제목·본문·자유 입력을 요청하거나 텔레메트리로 보내지 않는다.
- `GET/PUT /api/v1/threads/:threadId/feedback`는 세션과 책 소유권을 확인한다. PUT은 완성된 그림책만 허용한다. 모든 응답은 `Cache-Control: private, no-store`다.
- 브라우저는 계정 ID를 헤더로 보내 계정 전환 중 이전 화면의 요청을 거절하도록 한다. 계정/책 변경 시 컴포넌트를 새로 만들고 진행 중 요청을 취소하며, 로컬 저장소에 반응을 남기지 않는다.
- DB는 RLS로 다른 사용자의 읽기/쓰기를 막는다. 사용자 권한은 반응/이유 열만 쓰도록 제한하므로 소유자·책 ID·생성/수정 시각을 바꿀 수 없다. `save_reading_feedback`는 사용자 권한으로 동작하며 재시도는 같은 행을 갱신한다.
- 책 삭제 시 FK의 `ON DELETE CASCADE`로 반응도 삭제된다. 익명 사용자에게 테이블 및 RPC 권한을 주지 않는다.
- `/privacy`에 선택 수집 항목, 책 삭제 시 함께 삭제되는 수명, 기존 문의처를 통한 열람/삭제 요청을 안내한다. 화면은 반응 수정만 제공하며 반응 삭제는 운영자가 문의를 받아 처리한다.
- 이유는 평가와 맞는 고정 값만 허용한다. 긍정: 이야기/그림/주인공 맞춤. 아쉬움: 이야기/그림/길이/문장 난도. API와 DB에서 모두 검증한다.

## 운영에서 살펴볼 지표

서비스 역할 또는 DB 관리자로 아래 집계를 읽는다. 사용자별 원문을 추출하지 않아도 이유별 개선 우선순위를 확인할 수 있다. 비율의 분모는 응답한 책이며, 전체 독자의 만족도를 대표하지는 않는다. 이 반응이 생성 모델이나 프롬프트를 자동 변경하지 않는다.

```sql
SELECT rating, reason, count(*) AS books
FROM public.reading_feedback
GROUP BY rating, reason
ORDER BY rating, books DESC;
```

`npm run test:db`는 격리된 로컬 PostgreSQL에서 마이그레이션 재적용, 소유권, 익명 차단, 다른 계정의 변경 차단, 중복 방지, 이유 검증, 시각 위조 방지를 확인한다. API와 컴포넌트 테스트는 인증·검증·저장 실패·재시도·중복 클릭·계정 전환 중 응답 폐기를 검사한다.

## 기기의 읽기 기록과의 차이

즐겨찾기·이어 읽기는 `hodam-reading-library:v1:<계정 ID>` 로컬 저장소에 책 ID, 즐겨찾기 여부, 마지막 쪽/전체 쪽수, 최근 읽기/완독 시각만 저장한다. 큰 글씨(`hodam-reader-large-text`)와 잠자리 모드(`hodam-reader-bedtime`)도 같은 브라우저의 설정이다. 이 로컬 기록은 서버/분석 도구로 전송하지 않으며 다른 기기로 자동 동기화하지 않는다. 로그아웃 후에도 브라우저에 남고, 브라우저의 호담 사이트 데이터를 지우면 삭제된다. `/privacy`의 브라우저 저장 안내와 실제 저장 스키마를 함께 갱신한다.

계정/책 변경 시의 초기 렌더부터 이전 반응을 숨긴다. 같은 책에서 GET이 실패하면 폼을 열기 전 다시 확인하도록 하며, PUT 실패는 선택을 그대로 유지해 같은 키에 다시 저장한다. 서버 반영 후 응답만 끊겨도 재시도는 새 행을 만들지 않는다.
