# 아이와 단짝의 모험

## 구현 범위

오늘의 경험을 그림책으로 만드는 기존 흐름에 상상 모험을 더한다. 세계와 단짝을 고르면 교훈을 입력하지 않아도 시작할 수 있다. 완성한 모험의 마지막에는 같은 아이·단짝으로 다음 책을 만드는 동선을 제공한다. 앞 권을 읽지 않아도 이해되는 새 모험이며 이전 줄거리를 자동으로 이어 쓰지는 않는다.

## 디자인

- 시각 방향: 기존의 따뜻한 종이색·세이지색과 넉넉한 여백 안에서, 이야기의 장소와 단짝을 고르는 작은 서점 같은 화면.
- 구성: 일상/모험 선택 → 이름·나이 → 장소와 단짝 → 선택한 이야기의 출발점 → 기존 비용 안내와 만들기. 끝에서는 다음 모험이 주 행동.
- 상호작용: 선택 버튼의 배경/테두리 전환, 선택한 출발점의 짧은 등장, 다음 모험으로 돌아왔을 때 폼 제목으로 초점 이동. reduced-motion에서는 애니메이션을 생략한다.

## 데이터와 품질

- 선택한 세계·단짝 이름/종류·주인공 모습·실제 입력 나이를 책 JSON에 보관한다. 기존 책은 새 필드 없이 계속 읽는다. DB 변경 없음.
- 이어 만들기는 현재 소유자가 읽은 책에서만 준비하며, 계정에 묶인 일회성 메모리 전달로 이름을 URL에 싣지 않는다. 보류 중인 생성 요청이 우선한다.
- 세계의 사건과 단짝의 성격은 생성/검수/교정/삽화 모두에서 유지한다. 텍스트 기반 외형 설정을 고정하되 실제 삽화의 완전한 동일성은 보장하지 않는다.
- 새로 만들기 버튼은 폼만 열며 비용이 들지 않는다. 기존의 명시적 만들기, 인증, 차감, 재시도 계약을 유지한다.

## 확인

입력·옛 책 호환성, 저장 왕복, 단짝/세계 프롬프트, 교정 후 보호 필드, 계정 전환/보류 요청/StrictMode, 결말 다음 모험, 모바일 320/375/768 및 데스크톱 1280을 확인한다. 잔여 API 크레딧 부족으로 실제 유료 생성 품질은 별도 확인이 필요하다.
